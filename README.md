This Apple M1 run measured about `43.77 GB/s` at stride 1 versus `1.94 GB/s` at stride 128; the `i-k-j` matrix loop was `1.10x` faster than `i-j-k`. At eight processes, unpadded counters took `0.766 s`, hardware-line-padded counters `0.659 s`, and privatized counters `0.333 s`; the padding effect was modest on this host, so the measurements do not support claiming that 64-byte padding removed false sharing. Strong stencil speedup peaked at `2.21x` with four processes and was `1.81x` with eight; weak-scaling throughput reached `5.60x` at eight. The stencil arithmetic intensity is `0.25 FLOP/byte`; its observed effective bandwidth was about `4.40 GB/s`, roughly 10% of the stride microbenchmark ceiling, so it is bandwidth-sensitive but did not saturate that empirical bound. The operating system reports 128-byte cache lines; both the required 64-byte padding and a 128-byte hardware-line control are included.
